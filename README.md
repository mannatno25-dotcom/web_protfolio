# Mannat Agarwala — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — all portfolio sections and content
- `style.css` — layout, visual design, responsive breakpoints and dark theme
- `script.js` — theme switch, mobile menu, active navigation and contact form validation

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before submitting
- Replace bracketed education placeholders with your actual school, college, course and year.
- Replace sample achievement entries with certificates or achievements you have actually earned.
- Review skill percentages and project descriptions so they accurately represent your work.
- Add your real GitHub and LinkedIn profile URLs in the Contact section.
- Add your own profile photograph if you want one (the current hero uses a designed initials avatar).

## Contact form
The form validates the name, email and message in JavaScript, then opens the visitor's default email application with a pre-filled message addressed to `mannatno25@gmail.com`. It does not store submissions or send email through a backend.
